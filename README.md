# Навигатор AI — MVP (Бизнес Навигатор)

Пользователь вводит бизнес-идею → AI задаёт 5 уточняющих вопросов → генерируется документ:
анализ идеи · карта рисков · финансовая модель на 12 мес (считается кодом, не AI) · план запуска на 90 дней · рекомендации · экспорт в PDF.

**Стек:** Next.js 15 (App Router, TS) · Tailwind · Supabase (Auth magic-link, Postgres, RLS) · Claude API.

## Быстрый старт
1. `npm install`
2. Создайте проект на supabase.com → SQL Editor → выполните `supabase/migrations/001_init.sql`
3. Скопируйте `.env.example` → `.env.local`, заполните ключи
4. Supabase → Authentication → URL Configuration → добавьте `http://localhost:3000/auth/callback` в Redirect URLs
5. `npm run dev`

Полная инструкция деплоя: **DEPLOY.md**

## Архитектурные решения
- **Финансовая модель**: AI выдаёт только допущения (чек, объёмы, издержки); помесячный P&L считает `lib/fincalc.ts` детерминированно. Цифры всегда сходятся.
- **Prompt Engine** (`lib/prompts.ts`): все промпты в одном файле, со схемами JSON и guardrails (отказ от нелегальных идей, запрет выдуманных источников).
- **PDF**: печатная вёрстка `/project/[id]/print` + системный диалог «Сохранить как PDF». Ноль проблем с кириллическими шрифтами, работает на всех платформах.
- **Лимит**: 20 генераций/мес на пользователя (константа в `app/api/projects/route.ts`).
- **RLS**: каждая таблица закрыта политиками `auth.uid() = user_id` — чужие данные недоступны даже при ошибке в коде приложения.
